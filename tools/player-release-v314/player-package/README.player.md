# RED v0.314：赤色前线

可离线运行的原创单文件即时战略游戏。

## 立即开始

先读[开始作战速查](QUICK_START.html)，再[打开游戏](index.html)；打开游戏会离开速查页。[完整玩家指南](CURRENT_PLAYER_GUIDE.md)继续保留。

解压完整玩家包，用桌面浏览器打开同目录的[index.html](index.html)，建议全屏。选择战场等配置，或选择快速任务后，再点击“开始作战”；快速任务不会自动开始。第七项“双闸突进”预填双闸回廊／要点驻守／老兵／机动作战，仍可调整；它是胜利余量很小的进阶路线，不是安全或必胜攻略。

游玩无需账号、模型 API、联网、Python或Node.js。此包仅含游戏及当前操作指南，不附开发验证或版本历史。

## 本版购车工厂条件

购买新车时若没有已完工己方战车工厂，回执与生产按钮悬浮提示会区分三种情况：没有存活己方工厂时显示“需要已建成的战车工厂”；已有施工中工厂时显示“战车工厂施工中，完工后才能下新订单”；施工中且当前暂停时显示“战车工厂施工中；当前暂停，请继续游戏以推进施工”。不显示预计完成时间，也不保证完工后立即可下单，资金、队列等原条件仍适用。未开局、终局、重新部署确认与队列已满仍按原优先级拦截；失败不扣钱、不改已有订单，价格、施工、生产与长按保护规则不变。原生浏览器提示显示尚未验收。

## 本版工厂选择按钮

聚焦“选择全部已完工工厂”按钮后，按住空格再松开仍可正常选择一次，不再因长按重复事件丢失这次操作。仅保留本次尚未释放且有效的空格按下。长按期间若已失焦或取消、按钮在重复按键时已禁用、或战局已切换，仍不会保留这次按下。首次按下／松开、松开后重新按下、Enter与鼠标操作沿用原规则，不改变候选工厂、订单、资金或其他玩法。原生浏览器默认激活与长按效果尚未验收。

## 本版建造卡提示

建造卡不可用时新增直接可见的原因，依次优先显示尚未开始作战、战局已结束、重新部署确认，再显示机动作战禁止新建己方炮塔的规则限制，最后才显示资金不足。缺钱时显示“资金不足，还差 N资金”，N为当前资金缺口向上取整；恢复可用时清空原因。暂停时若原条件满足仍可建造。提示不预留或扣除资金，不改变原禁用条件、价格、建造时间、放置条件或挑战规则，也不新增实时播报。卡片可用不保证任意位置都能放置，仍需选点检查。原生浏览器排版与读屏效果尚未验收。

## 本版购车资金回执

按4–8购买新车而资金不足时，回执明确车型与当前资金缺口，格式为“车型新订单资金不足，还差 N资金”，N为实际缺口向上取整。只有当前生产订单队列非空时，才附加“已付订单保留”，包括已分配工厂、排队或等待出口的已付订单；保留不保证立即推进生产，暂停、缺电等条件仍然适用。队列已满或缺少已建成工厂仍优先显示原提示，未开局、终局与重新部署确认期间仍不下单。失败不扣钱、不改已有订单；价格、生产规则、成功回执与原有长按保护不变。原生浏览器显示尚未验收。

## 基础操作

- 左键点选或拖框选车；右键下达普通命令。
- 按A后左键下达攻击移动。
- 空格暂停／继续；暂停仍可选择、下令和付费排产。
- Esc取消待建造或待点选操作。

输入框、下拉框和输入法组字期间不触发游戏快捷键；按钮聚焦时空格／Enter用于激活按钮。 聚焦“攻击移动 [A]”或侧栏建造按钮时，长按Enter产生的非输入法系统重复按键会被阻止默认激活，避免重复切换待攻击或待建造操作。首次Enter、松开后重新按下、空格与点击沿用原规则；输入法组字和keyCode 229事件不受这项新增拦截影响。此项只按事件的repeat标记处理，不是时间间隔限制，不改变单位命令、建造价格、资金或其他玩法规则。原生浏览器默认激活、键盘时序、焦点与输入法效果尚未验收。更多操作见[当前玩家指南](CURRENT_PLAYER_GUIDE.md)。

## 可选车辆与建筑外观预览

音效／速度旁的“显示预览”默认折叠，里面的“实验性车辆与建筑外观预览（各5种）”默认关闭。启用后可试用5种车辆和5种建筑轮廓，随时取消即可恢复原外观；仅本页面会话保留，新局沿用，重新打开页面恢复关闭。它不改变单位属性、选择或命令。新外观可能增加绘制开销，原生浏览器效果和帧率尚未验收。

指挥中心、发电站、精炼厂和战车工厂有辅助阵营标记：双横条为己方，三角为敌方。四类建筑的小标记仅作辅助识别；炮塔不加标记，无标记不代表中立，也不能据此判断阵营。标记在施工遮罩和状态层下方，施工或缩小显示时可能难辨。

建筑预览保留原有炮塔朝向、总部旗杆、施工遮罩／倒计时与施工、工厂生产状态条。当前首次启用最多懒建30条静态路径（车辆10＋建筑20）；API缺失或失败时直接绘制，直接路径可能增加调用开销。预览不写入战局或存档。原型调用计数中，双方四类建筑各一座的一帧增加44次缓存Canvas方法调用或64次直接调用，包含保存／恢复上下文与坐标转换；这是额外开销计数，不是实际帧率测量。

沿用的矿石标签调整减少矿石标签布局在单次计算内重复拼接障碍框数组，不跨帧缓存，不改变标签位置；这不是FPS改善承诺。

## 保存与备份

**需要手动保存。刷新、关闭页面或开始新局会丢失未保存进度；离页提示不是自动保存。**

本地存档受浏览器、文件位置及存储策略影响。移动HTML文件前先导出JSON备份；换设备、浏览器或打开路径不保证原槽自动迁移或可见。

“导出所选存档”只导出槽内已有快照，不保存当前局。备份最新进度请用“保存本局并导出”，或先确认保存成功再导出。“已发起下载”不等于下载完成，请核对浏览器下载列表和实际文件。

保存会覆盖所选槽；载入会替换当前局。导入需确认覆盖所选槽，但不会立即换局，导入成功后仍须另行载入。覆盖、取消读取及并发限制详见[存档、备份与恢复](CURRENT_PLAYER_GUIDE.md#6-存档备份与恢复)。

## 矿田图示

矿田中的矿块图示会随绝对余量分为粗略三档：大于4500显示8块，1500以上至4500显示4块，正数至1500显示1块；耗尽仍不绘制。矿块不是精确数量或剩余百分比，具体量仍以原数字标签和悬浮信息为准；部队、建筑或其他图层可能遮住图示。位置、颜色、底盘、采矿与经济规则不变，不新增开关。玩家包新增独立速查页，供打开游戏前快速了解操作。原生浏览器效果与FPS尚未验收。

## 低矿量标签

正数且不足1000的矿点，标签改为向上取整的整数，例如余量250显示“矿 250”；999.5显示“矿 1000”，不表示精确小数。1000及以上继续按原规则向上取整为k单位，耗尽仍不显示。8／4／1块粗档图示、采矿和经济规则不变。文字宽度变化可能使原避让逻辑选择不同位置；原测量、候选点、夹取与回退规则保持，measureText调用可能增加，不承诺FPS提升。图示和文字仍可能被后续图层遮挡，原生浏览器效果尚未验收。
