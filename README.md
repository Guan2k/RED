## v0.267：选择矿车当前交矿精炼厂

单选一辆正在返厂交矿或等待交矿结算的己方矿车时，侧栏显示“选择当前交矿精炼厂”，附当次判定的建筑编号和中心坐标。点击只选择这座精炼厂，方便接着查看或使用既有建筑操作；不会更改矿车命令、指定矿点、载矿、资金或编队，也不移动视角。

目的地沿用实际采矿规则：选择矿车当前位置最近的存活、已完工己方精炼厂。满载、已接受的提前返厂，以及全图矿石耗尽时的带矿返厂都按原规则判定。显示是当前界面判定；建筑毁坏、新厂完工或矿车移动后，点击会重新判断，可能选择另一座厂。这不是固定绑定或最短／安全／可达路线保证。

手动移动、仍在采矿或前往矿点、无已完工精炼厂、空载、非己方矿车及多选时不提供此入口。暂停时可用；未开战、重开菜单和终局不能操作。选择目标后按既有选择动作清除待建造、攻击、普通／追加点选和拖选，不替矿车下任何新指令。

## v0.265：一次清除后续队列

选中已有分段路线或攻击排队的战斗车辆，点击“清除后续队列”。符合条件的车辆各自保留正在执行的指令，一次取消其余路点或待攻击目标。这是减少重复撤销操作的便利入口；原“撤销队尾”、停止、普通指令和追加队列点选继续使用原规则。

按钮显示当下可处理的车辆数，点击时重新检查。暂停可用；未开战、重开菜单及终局禁用。没有后续项时重复点击不产生额外操作。与原撤销队尾一样，尚未提交的点选模式保留；若不再需要待点选操作，请用原取消入口取消。

## v0.264：一次性追加队列点选

选中战斗车辆后，点击“追加队列点选”，再用主指针在地图有效位置按下、抬起一次。点空地尝试追加普通路线，点敌军尝试追加攻击目标；沿用原Shift＋右键的资格、重复目标和最多8项（含当前）限制。只追加符合条件的战斗车辆，矿车、维修车和工厂不会因此改成移动、跟随或集结命令。

有效点选抬起后尝试一次并退出，包括因友军占位、目标重复、队列已满或单位当前命令不兼容而拒绝的情况；请看既有命令回执。它不替换当前任务，不混排两类队列，也不保证道路可达或敌人到抬起时仍然有效。当前段原为攻击移动时继续保留，后续追加地面路段按原规则普通移动。

新模式有独立的待点选说明与取消文字，不显示普通替换命令的候选预览。普通指令点选、A攻击模式、普通／Shift＋右键及撤销队尾保持原义；新模式里的修饰键不改变追加含义。拖动超过8地图单位、地图外抬起、取消／失焦等按既有点选生命周期取消，暂停可排队但不会推进模拟。这里只新增主指针点选入口，不声称已经完成真实触控设备验收。

## 矿车工作阶段定位（v0.242）

展开侧栏“矿车工作概览”，选择一个工作阶段，再点击“选择此阶段矿车”。按钮数字是界面本次刷新快照；点击会重新筛选全图存活、已完工己方矿车，零匹配会保留原选区并提示。

暂停时可选；未开始、重新部署菜单和终局不可选择，仍可浏览阶段快照。下拉框聚焦时不触发游戏快捷键。阶段选择只保留在当前页面，不写入存档；新局及成功载入后沿用下拉选项、清空上次选择回执。回执仅说明那一次选择，不保证矿车此后仍处同一阶段。

## 启动与开局

1. 解压玩家包，用桌面浏览器打开 `index.html`。游戏无需安装、账号、模型 API 或联网；Node.js 只用于下方测试，不是游玩依赖。
2. 选择战场、胜利条件、难度与规则，或点击一个“快速任务”。
3. 点击“开始作战”（再次开局时为“再次作战”）。预设只填选项，不会自动开始。

重新部署前先保存。下次开局的四项配置会在“返回战场”、重新打开菜单和本局结束后保留；开始新局才应用，成功载入则改用存档配置。“机动作战”只禁止己方新建炮塔。

## 本地存档、备份与恢复

**需要手动保存。刷新、关闭页面或开始新局会丢失未保存进度；离页提示不是自动保存。**

三个槽位保存在浏览器本地，菜单和侧栏的槽位选择同步；切换槽位本身不会载入。浏览器、文件路径和存储策略可能影响槽位可见性，换设备或浏览器不会自动迁移。重要进度请另存 JSON 文件。


### 三个存档槽概览（v0.241）

菜单与侧栏存档区新增默认折叠的只读概览。展开或点击“刷新概览”时读取三个槽位，显示空、有效、格式异常或存储读取失败；有效槽显示战场、胜利条件、难度、规则、游戏时间和记录时间。单槽异常不影响其余两槽。

概览是本次读取的快照，不跨页面实时同步，也不是三个槽位的原子快照；需要最新内容请刷新。两个入口共享最近一次读取结果。本页成功保存或导入后只标记“概览需刷新”，不会反复读取。概览不会切槽、载入、保存、导入或删除；仍用原有槽位选择器和按钮操作。暂停、重新部署及终局均可查看。

### 保存与导出：三个按钮的区别

- **保存进度**：把进行中的当前局写入所选槽，替换该槽快照，不发起文件下载。
- **保存本局并导出**：先保存当前局到所选槽，只有保存成功才发起这次快照的 JSON 下载。不会自动换槽，也不会在保存失败后转而导出旧档。
- **导出所选存档**：只下载所选槽已有的快照，不先保存当前局。要备份最新进度，请用上一按钮，或先确认“保存进度”成功再导出。

暂停及重新部署菜单中的进行中战局仍可保存；未开局或已结束时不能保存当前局。超过 1000 个双方车辆与建筑、数据校验、体积或浏览器存储问题均可能阻止保存；写入前失败不会覆盖旧槽。若写入已成功但状态显示异常，已写入的快照不回滚，请按页面提示核对。

“保存本局并导出”下载的是本次成功保存的确切快照，不再次读取槽位。保存成功但下载请求失败时，快照不回滚；可核对槽内仍是所需快照后重试“导出所选存档”。其他页面可能已改写该槽，重试会导出它届时的内容。

**“已发起下载”不等于下载完成。** 页面无法确认下载完成或用户取消；请检查浏览器下载列表和实际文件。

### 载入、导入与取消读取

- 选槽后点击载入，才会替换当前局；替换进行中战局需确认。成功载入后默认暂停，配置以存档为准，点击继续后作战。
- 导入 JSON 需确认覆盖所选槽，但不会立即换局，导入成功后仍须再载入。读取完成或确认后，若所选槽与开始读取时不同，或目标槽内容已变化，则停止；请核对后重新选择文件。
- “取消读取”只使尚未完成的文件读取结果失效，不删除存档、不改变当前局，也不撤销已完成的导入。底层读取可能继续，但其结果不再用于导入。
- 重新打开文件选择器后取消选择，不等于取消此前正在读取的文件；要停止它，请点“取消读取”。选择新文件会替代旧读取。

存档格式仍为版本 1，旧档必须通过当前校验；新内容建议用同版或更新程序打开，旧程序能打开不代表完整兼容。并发检查不是跨页面原子锁，也不能识别内容变化后又恢复为完全相同字节的情况。避免多页面同时改写同一槽，并保留文件备份；读档不保证逐帧重演。

## 先记住这些操作与区别

- 左键点选或拖框选车，右键下达普通命令；A 后左键为攻击移动。“普通指令点选”先进入模式，在地图抬起有效点按时尝试一次普通右键命令，随后退出；拖动超过 8 地图单位或在地图外抬起会取消。此模式的 Shift／Alt 不追加路线或切换攻击移动。
- 空格暂停／继续。暂停时仍可选择、下令和付费排产；切到后台会自动暂停，返回后手动继续。速度同时影响双方。输入框、下拉框和输入法组字期间不触发游戏快捷键；按钮聚焦时空格／Enter用于激活按钮。
- S 取消当前车辆命令，不是冻结或停火；战斗车仍可自动交战。H 坚守不主动追击，但不锁定碰撞位置。O 驻点警戒可能追击离开占点圈。待建造或待点选可用 Esc／“取消待点选操作”退出；下拉框聚焦时，退出重新部署请用“返回战场”。
- 订单状态文字只读；**“取消订单”按钮**普通点击立即取消并按剩余生产比例退款；Shift 点击调至等待首位，Alt 点击选厂，两键同时按时 Alt 优先。独立“移到等待首位”和“选择此订单工厂”按钮只执行各自动作，修饰键不改变含义。显示的“还需生产 N 秒”是游戏秒工作量，不是现实出厂倒计时。
- “选择出厂点占位友军”只选车，不自动清出口；“仅选受损战斗车”只筛当前选区，不自动撤退或修理；“选择受损建筑”免费选一座，R／“修理建筑”才按报价付费修理。
- 岩石提示的金色外圈内是该岩的空地点令拒绝范围；敌军目标与普通模式护航点另判。圈外不保证可达，重叠处还须避开其他岩石。岩石挡移动和建造，不挡炮弹；给矿车通道和工厂出口留空地，火炮需要掩护。

所有模式都须保护己方指挥中心，也可摧毁敌方指挥中心获胜；基地毁坏优先结算。争夺需至少两座有效据点累计 90 游戏秒；要点驻守需拥有标记点并留战斗车累计 90 有效秒；采矿只算实际交付的 10000 矿石；守卫为己方指挥中心存活 360 游戏秒。占点只计算坦克、侦察车和火炮，矿车、维修车及建筑不算；归零、暂停及并列结算等细则见玩家指南。
