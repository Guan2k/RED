## 立即开始

1. 下载并解压完整同版包，用桌面浏览器打开本目录的 [index.html](index.html)，建议全屏。
2. 选择战场、胜利条件、难度与规则，或选择一个快速任务。
3. 点击“开始作战”。快速任务只预填配置，不会自动开始。

无需安装、账号、模型 API 或联网；Node.js 只用于测试，不是游玩依赖。仓库中的游戏文件链接不等于在线试玩页面，以下载后本地打开为准。

## 先会四个动作

- 左键点选或拖框选车，右键下达普通命令。
- 按 A 后左键下达攻击移动。
- 空格暂停／继续。暂停时仍可选择、下令和付费排产。
- Esc 取消待建造或待点选操作。

输入框、下拉框和输入法组字期间不触发游戏快捷键；按钮聚焦时空格／Enter用于激活按钮。详细操作见[选择、编队与地图命令](CURRENT_PLAYER_GUIDE.md#3-选择编队与地图命令)，开局与重开见[开局说明](CURRENT_PLAYER_GUIDE.md#1-开局暂停与重新部署)。

## 建筑进度条显示修正

施工与工厂生产进度条现在完整位于原有裁剪框内，原外观和预览外观均适用。只上移条带位置，进度、状态文字、颜色、宽度和生产／施工规则不变。

## 可选车辆与建筑外观预览

音效／速度旁的“显示预览”默认折叠，里面的“实验性车辆与建筑外观预览（各5种）”默认关闭。启用后可试用5种车辆和5种建筑轮廓，随时取消即可恢复原外观；仅本页面会话保留，新局沿用，重新打开页面恢复关闭。它不改变单位属性、选择或命令。新外观可能增加绘制开销，原生浏览器效果和帧率尚未验收。

四类建筑的小标记仅作辅助识别；炮塔不加标记，无标记不代表中立，也不能据此判断阵营。标记在施工遮罩和状态层下方，施工或缩小显示时可能难辨。

建筑预览保留原有炮塔朝向、总部旗杆、施工遮罩／倒计时与施工、工厂生产状态条。当前首次启用最多懒建30条静态路径（车辆10＋建筑20）；API缺失或失败时直接绘制，直接路径可能增加调用开销。预览不写入战局或存档。原型调用计数中，双方四类建筑各一座的一帧增加44次缓存Canvas方法调用或64次直接调用，包含保存／恢复上下文与坐标转换；这是额外开销计数，不是实际帧率测量。

沿用的矿石标签调整减少矿石标签布局在单次计算内重复拼接障碍框数组，不跨帧缓存，不改变标签位置；这不是FPS改善承诺。

## 新快速任务：双闸突进

第七项快速任务预填“双闸回廊／要点驻守／老兵／机动作战”。这是一组现有规则组合，按钮不自动开始；开局参考提供西侧分散驻守、火炮与跟随维修的进阶思路。路线余量很小，不保证获胜。六项原任务保持不变。

## 编队快捷键防连发

按住1–3或Ctrl／⌘＋1–3只执行首次按键；系统自动重复事件不会再次召回或保存，避免后来选区被覆盖、待点选操作被取消。松开后再次按键仍可正常操作，界面按钮和Ctrl点击不变。这只按键盘事件的重复标记处理，不是时间间隔限制。

## 编队空选保护

Ctrl／⌘＋1–3 或 Ctrl＋点击编队按钮时，若没有选中存活己方车辆，会保留原编队并显示原因。只有建筑、敌方、已毁车辆或空选择都不会清空编队。有效保存仍替换该组；矿车、维修车仍可入组，召回与暂停规则不变。

## 可选开局练习

在“指挥建议”后展开练习清单：实际交回180矿石、实际生产1辆增援、本局曾占领1座据点。载货未交、订单未出厂、占领未完成都不计完成；循环生产计入，失去据点仍保留“曾完成”。已有累计记录可显示进度，旧记录缺省按0且不回推，新局归零。

练习只显示进度，不发奖励、不自动下令或暂停，也不改变胜利条件。敌军仍在行动，可自行暂停阅读；三项完成后继续原战局。

## 保存与备份提醒

**需要手动保存。刷新、关页或开始新局会丢失未保存进度；离页提示不是自动保存。**

本地槽依赖浏览器、打开位置及存储策略，换浏览器、设备或文件位置不能保证原槽可见。重要进度请导出 JSON 备份。

“导出所选存档”只导出槽内已有快照，不会先保存当前局。备份最新进度请用“保存本局并导出”，或先确认保存成功再导出。“已发起下载”不等于下载完成，请核对浏览器下载列表和实际文件。

覆盖、导入、载入与取消读取规则见[存档、备份与恢复](CURRENT_PLAYER_GUIDE.md#6-存档备份与恢复)。
