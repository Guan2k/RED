这是 v299 之后候选改动的隔离原型，尚未升级版本、迁移、发布或改写 v298/v299 产品。基于已提交 v297 完整 index.html，只在侧栏已有 `openingPractice` 后、`unitReference` 前插入一个默认关闭的 `details.controls-help`。整段执行 JavaScript、CSS、原有 DOM 标记和显示版本逐字不变。

## 为什么现有入口不足

- `quickMissionTips` 位于开局遮罩，战局中不能直接查看；其中“斜线守卫”仍是标准难度的概述，未含这份休闲新手路线的完整坐标、预算和维护阈值。
- `openingPractice` 是采矿、生产和占点三项累计练习，不是守卫路线，也不改变胜利条件。
- 因此不新增第八个预设、不复制全部七项简介，只增加这一份限定配置的参考。位置在侧栏帮助区、现有练习之后，可在战局中滚动查看；不新增地图覆盖物或开局菜单条目。

## 原型边界

首行明确仅适用于准备新局时选择“斜线前哨 / 守卫 / 休闲 / 标准”，对应 `classic/survival/easy/standard`；不会切换当前战局。保留最终指南六步及关键条件，使用准确的“新战车：改为坚守”现有按钮文案。

只含原生 details/summary、说明段落与六步列表。不新增游戏按钮、链接、脚本、存储、配置动作或快捷键；明确提示展开不会自动暂停、阅读可点击暂停按钮；说明标题聚焦时空格只展开/收起，不暂停战局。展开状态仅是原生 DOM 状态，未加入存档，也未新增跨新局自动收起逻辑。用户需自行暂停阅读，并在每次检查后继续。

证据仍明确归属于 v0.297 限定源码模拟，不宣称已经验证未来版本、原生浏览器落点或新手实操。三种固定种子在每条策略内轨迹相同，不是统计胜率；对照失败也不表示坚守在全部战局无用。

## 检查和局限

`node check.cjs` 运行只读专项验证。覆盖：
- 原型精确移除新增片段后恢复完整基准；整段 JS/CSS 不变。
- 默认关闭、原生 summary、ARIA说明目标、侧栏正确位置、无外链/新控件/事件属性。
- 八图同种子新局的完整 state 和关键输入状态、全部原有 DOM 字段/层次精确对照。
- summary 聚焦时 Space/Enter（首次/重复）不触发暂停或阻止原生激活；原有 F/H 快捷键行为保持一致。
- 模拟原生 toggle 后无战局/存储变化；错误预算、坐标、顺序、继续提示、坚守指引、证据声明、开启默认值及越界位置等负例。

VM 不实现浏览器原生 details 的默认键盘展开动作；测试证明的是既有游戏监听器边界与静态原生语义。原生鼠标/键盘展开、侧栏真实渲染、窄屏滚动、读屏尚未验收，不将其记作已通过。未运行大聚合或重跑六分钟策略。
