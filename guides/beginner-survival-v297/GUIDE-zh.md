# 休闲守卫：先学会补兵与维修

目标：让自己的指挥中心存活到游戏计时 06:00。暂停不计时；不必追着敌人进攻。

1. 在新战局菜单点「斜线守卫」，再把难度改为「休闲 · 敌军初始资金900 / 决策较慢」。保持「标准规则」，点「开始作战」，立即点「暂停 [空格]」。暂停时可以慢慢安排开局。
2. 建「发电站」（300资金，5秒），落在地图坐标（100,500）；建「防御炮塔」（450资金，7秒），落在（400,520）。选择建筑后在地图点击放置，以可放置预览为准。坐标以左上角为原点，向右为X、向下为Y。再买一辆「主战坦克 [4]」（350资金，6秒）。这三项共1100，初始1700余600。
3. 若仍有建造预览，先点「取消待放置」，或在输入框外按 Esc，退出放置模式；取消尚未落地的预览不会扣款。再下达部队或工厂命令。点「选择全部已完工工厂」，在（360,600）右键设置集结点。点「作战车辆 [F]」，在（340,570）右键移动。保持默认自由接敌，不开启工厂新车或部队的“到达后坚守”。原地坚守的对照路线未能守到6分钟。
4. 先选「循环车型目标：5（含订单）」，再选「循环补单保留：300」，最后开「全局循环：主战坦克 · 350」。其他生产设置保持默认。补兵正常花钱，已付订单也计入目标；这不是额外赠兵；保留300只约束新的循环订单，手动购买、建造和维修仍会花钱。点「继续 [空格]」。
5. 大约每半分钟暂停看看基地。若已没有存活矿车且资金至少700，买一辆「采矿车 [8]」（400资金，7秒）。资金至少400时，若「选择受损建筑 [B]」可用，点它；选中的建筑生命不超过四分之三且修理可用，就按一次修理，然后继续。修理按按钮显示的费用扣钱，每次最多恢复300生命、最多花100资金。无论是否购买或修理，检查完都点「继续 [空格]」。不要为了检查而把部队不断拉回原位。
6. 坚持到06:00的实际胜利提示。后段仍可能损失矿车和部队，留意补给；暂停检查比匆忙操作更容易。

验证范围：v0.297 的完整游戏源码模拟，三组固定种子均守到360秒；把每次维护延后15游戏秒后，同三组也获胜，记录检查点中的指挥中心均为1800/1800。同一策略下三组种子的已记录轨迹相同，不能当作多种随机战况的胜率统计。它是可参考的入门练习，不是任意操作、任意地图的必胜保证；尚未验证真实浏览器中的鼠标落点误差和新手实操体验。
